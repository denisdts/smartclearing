# SmartClearing

Мобильное приложение на Expo (React Native + TypeScript, Expo Router).

## Экраны

1. **Вход** — логин и пароль, кнопка «Войти», ссылка «Восстановить пароль».
2. **Выбор дома** — стартовый экран после авторизации.
3. **Выбор подъезда**.
4. **Выбор этажа**.
5. **Выбор места на этаже**.
6. **Фотографии места** — встроенная камера, несколько снимков, удаление и переход к синхронизации.
7. **Синхронизация фотографий** — очередь снимков с загрузкой в API и прогрессом.
8. **Настройки** — аккаунт, переключатели, выход.
9. **Описание** — инструкция и информация о приложении.

На всех экранах приложения в шапке доступны иконки перехода к настройкам,
описанию и синхронизации.

## Требования

- Node.js 22 LTS или новее
- npm
- Для запуска на телефоне — приложение **Expo Go** (iOS / Android)

## Установка

```bash
npm install
```

## Локальный запуск

```bash
npm start
```

После запуска Metro откройте:

- **Android** — нажмите `a` (нужен эмулятор или подключённое устройство) либо отсканируйте QR-код в Expo Go;
- **iOS** — нажмите `i` (нужен симулятор macOS) либо отсканируйте QR-код камерой в Expo Go;
- **Web** — нажмите `w`.

Отдельные команды:

```bash
npm run android
npm run ios
npm run web
```

Телефон и компьютер должны быть в одной сети. Если QR-код не подключается, запустите туннель:

```bash
npx expo start --tunnel
```

## Авторизация

Вход выполняется через `POST /api/auth/login` сервиса SmartClearing. Вместе с
короткоживущим `access_token` API выдаёт `refresh_token`. При истечении
access-токена приложение автоматически обновляет его через
`POST /api/auth/refresh` — при запуске, при возврате приложения на передний
план и при ответе `401` — после чего повторяет исходный запрос. Повторный вход
требуется только если истёк refresh-токен (по умолчанию 30 дней).

Сессия сохраняется через `expo-secure-store` (на web — `localStorage`) только
при включённом переключателе «Запоминать авторизацию» на экране настроек.
Если он выключен, сессия живёт в памяти до закрытия приложения.

Адрес API по умолчанию — `https://smartclearing.ru/api`. Для локальной
разработки его можно переопределить переменной окружения
`EXPO_PUBLIC_API_URL`.

Выход из аккаунта — на экране настроек.

## Фотографии

Снимки, сделанные на экране места, копируются в документы приложения и
попадают в локальную очередь. На экране синхронизации очередь загружается в
`POST /api/photos`; после успешной загрузки фотография и её файл удаляются с
устройства. Неудачные попытки остаются в очереди с текстом ошибки и могут быть
повторены. На web очередь хранится только в памяти текущей сессии.

Полное описание контракта API — в [docs/api.md](docs/api.md).

## Push-уведомления

Приложение использует `expo-notifications`. При включении переключателя
«Push-уведомления» на экране настроек оно запрашивает разрешение, создаёт
Android-канал `default` и регистрирует Expo push-токен через
`POST /api/push-tokens`. При выходе из аккаунта токен удаляется через
`DELETE /api/push-tokens`.

Нажатие на уведомление открывает путь из поля `data.url` через Expo Router,
например `/sync` или `/house/1/entrance/2/floor/3/place/4`.

Сервер отправляет уведомления через Expo Push Service. Автоматические
уведомления приходят при первом фотоотчёте по месту, ручная рассылка доступна
в админке сайта (`/local/admin/push.php`).

Для Android нужны FCM V1 credentials, для iOS — APNs key в Expo/EAS. На
Android push не работают в Expo Go: требуется development или production build.
После изменения нативного состава (`expo-notifications`) нужно пересобрать
приложение: `npx expo run:android` или `eas build`.

## Сборка APK

```bash
npx expo prebuild --platform android --no-install
cd android
./gradlew assembleRelease
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`.
Копия для установки: `dist/SmartClearing-1.0.0.apk`.

Сборка `release` в сгенерированном проекте подписана debug-ключом и подходит
для локальной установки и тестирования. Для публикации в Google Play настройте
собственный keystore или используйте EAS Build.

## Структура

```text
src/
  app/
    _layout.tsx                     # провайдеры авторизации и очереди фото
    login.tsx                       # экран входа
    (app)/
      _layout.tsx                   # шапка с иконками разделов
      index.tsx                     # выбор дома
      settings.tsx                  # настройки
      about.tsx                     # описание
      sync.tsx                      # синхронизация фотографий
      house/[houseId]/entrances.tsx # выбор подъезда
      house/[houseId]/entrance/[entranceId]/floors.tsx        # выбор этажа
      house/[houseId]/entrance/[entranceId]/floor/[floorId]/places.tsx
      house/[houseId]/entrance/[entranceId]/floor/[floorId]/place/[placeId].tsx
  api/                              # клиент REST API и методы справочников
  auth/                             # контекст и хранение сессии
  photos/                           # очередь снимков и её хранение на устройстве
  hooks/                            # загрузка данных API
  components/                       # общие UI-компоненты
  data/                             # типы данных
  theme.ts
```

Справочники (города, дома, подъезды, этажи и места) загружаются из API.
Контракт описан в [docs/api.md](docs/api.md).
